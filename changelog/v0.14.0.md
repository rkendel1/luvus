Luvus v0.14.0 introduces a state graph for recording workspace, pane, and agent mutations, along with the foundation for a native desktop GUI. Existing v0.13.1 workspaces and settings remain supported after upgrading.

## Features

- **State graph:** Record every workspace, pane, and agent mutation as a typed operation that agents can query for full context about what has happened.
- **Agent context:** Query workspace state and recent operation history via the new `workspace.context` API (Phase 2).
- **Desktop GUI foundation:** Build with `--features gui` for a GPU-accelerated native window using wgpu + winit (Phase 1 stub, full feature parity planned for Phase 3).

## Architecture

- **StateDb:** An in-memory CRDT-style operation log with automatic pruning, time-based queries, and checkpoint persistence.
- **StateOp types:** Typed operations for workspace, pane, tab, agent, task, and file mutations.
- **AgentContext:** Structured context that agents can request to understand current state and recent history.
